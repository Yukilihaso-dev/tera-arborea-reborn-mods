# TERA Arborea Reborn Mods

[Visual Cleanup](arborea-visual-cleanup) removes nostrum hand glow on all players, blue flashes, flying dash blur, vignette and camera shake.

Version 1.2.1 is a new experimental character-selection settings patch for the pinned Arborea client. It is disabled by default and requires the new `applyVideoSettingsAtCharacterSelectV2` opt-in. The retired 1.2.0 flag is ignored, even when an old config contains `true`. The original 1.2.0 UI packages remain withdrawn after a tester reported a crash.

Read the [mod instructions](arborea-visual-cleanup/README.md) before installing or testing. Preserve your five original cleanup settings when replacing the module. This build requires in-game tester validation; offline checks do not establish that its native crash is resolved. See [verification and recovery guidance](TESTING.md).
